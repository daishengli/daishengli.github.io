iamajmeena/neonclipping：2927 star 的本地 AI 剪辑引擎，把 85 分钟直播剪成竖屏短视频只要 97 秒

发表于 2026-11-28 分类于 开源项目

neonclipping 是印度 Jaipur 的导演 Ajay K Meena 用 Python 写的本地短视频剪辑引擎，2026 年 11 月 19 日上线，五天后拿到 2927 个 star 和 194 个 fork，AGPL-3.0 许可证（2026 年 11 月 24 日之前发布的版本仍是 MIT）。它解决的是 OpusClip 这类云端剪辑服务的核心痛点：一条 85 分钟的直播录屏上传上去要等几十分钟还按分钟计费、素材还留在别人服务器上。它最核心的思路是「音频优先」——先只下载 79 MB 音频，用 YouTube 自带的逐词字幕拿到 transcript，靠响度突变、2-4 kHz 人声能量、optical flow 运动量和静音到爆发过渡打分挑出候选片段，再让本地 Ollama 模型读候选段落的文字打分、写标题和 hook，最后只下载被选中那几秒视频片段，用 FFmpeg 烧录字幕输出 1080x1920 竖屏成片。README 实测 RTX 2060 上 85 分钟 YouTube 直播剪 3 条用 97 秒，3 小时 Twitch VOD 用 136 秒。项目还包含 11 种主播画面布局、5 种字幕样式、52 种字幕语言、自动找摄像头框的 YuNet 人脸检测、基于聊天热度突增的直播实时剪辑、手机远程控制、本地 MCP 接口给 Agent 调用，以及直接发布到 YouTube、Instagram、TikTok 的凭证对接。全部跑在本地，服务默认只监听 127.0.0.1。

jingyaogong/minimind：7 万 star 的中文极简 LLM 教学项目，2 小时 3 块钱从零训出 64M 大模型

发表于 2026-11-27 分类于 开源项目

jingyaogong/minimind 是 GitHub 上最受欢迎的中文从零训练 LLM 教学项目之一，累计 71615 个 star、9298 个 fork，Apache-2.0 协议，纯 Python 实现，2024 年 7 月建仓至今保持高频提交。它用原生 PyTorch 把大语言模型从零到一的完整链路全部摊开，涵盖 Tokenizer 训练、预训练、监督微调、LoRA、知识蒸馏、DPO、PPO、GRPO、CISPO、Agentic RL、Tool Use、自适应思考等环节，目标是让个人开发者用单卡 RTX 3090 在约 2 小时、3 元人民币内复现一个 64M 参数的对话模型。主线 minimind-3 结构对齐 Qwen3 生态，Pre-Norm 加 RMSNorm、SwiGLU 激活、RoPE 加 YaRN 外推、q_heads 8 与 kv_heads 4、词表仅 6400、8 层 768 维；MoE 版本 minimind-3-moe 为 198M-A64M、4 专家 top-1 路由。兼容 transformers、trl、peft 训练框架与 llama.cpp、vllm、ollama、sglang 推理引擎，开源全阶段中文数据集、OpenAI 协议兼容 API 服务端与 Streamlit WebUI，并附 C-Eval、C-MMLU、ARC-Easy 等第三方测评结果，README 主动披露了评测标准误与数据污染对照，诚实标注工具调用泛化不足、奖励稀疏等真实局限。

firecrawl/firecrawl：20.9 万 star 的 AI Agent 抓取基础设施，AGPL-3.0 开源自托管，一个 Rust 二进制把网页变成 Markdown

发表于 2026-11-25 分类于 开源项目

firecrawl/firecrawl 是 GitHub 上星标最多的 AI Agent 数据基础设施项目之一，累计 208914 个 star、10916 个 fork，AGPL-3.0 协议（SDK 为 MIT），主语言 TypeScript，2024 年 4 月建仓至今高频提交。它是一套把网页变成干净 Markdown 的清洗引擎加统一 API，核心能力包括 scrape 单页抓取、crawl 整站爬取、map 站点 URL 发现、batch scrape 批量抓取、search 搜索、interact 浏览器交互、agent 自主取数，以及 Alexandria 的 550 多个数据源。项目提供三种形态：apps/local 是 Rust 单二进制，不依赖数据库队列容器，可本地跑抓取、把 v2 API 服务在 3002 端口并以 MCP 接入 Claude Code、Cursor、Codex 等；apps/api 是 Docker Compose 编排的完整自托管服务端，含 API、worker、Playwright、Redis、RabbitMQ、NuQ PostgreSQL；Firecrawl Cloud 是官方托管服务，宣称 96% 网页覆盖率与 3.4 秒 P95 延迟。仓库另含 Python、Node.js、Go、Java、Rust、Ruby、.NET、PHP、Elixir 九套 SDK。

EL4CTEO/fast-anything：1869 star 的工具，让 AI Agent 只把最慢的 5% 改写成 Rust 并证明行为一致

发表于 2026-11-23 分类于 开源项目

fast-anything 是 2026 年 11 月 21 日上线的新项目，两天拿到 1869 个 star，MIT 许可证，主语言 Rust。它不做整应用重写，而是先用各语言自带的 profiler 把一次真实运行里的函数按耗时与可移植性排序，筛出既慢又干净的热点，再让 Claude Code 或 Codex 等编码 Agent 只把这些函数改写成 Rust，最后用录制的真实调用逐条回放比对：只有返回值一致、异常类型一致、单次调用不比原实现慢，才允许启用。工具支持 Python、JavaScript 与 TypeScript、Ruby、Java、Go、PHP、C、C++、C# 等十种语言，绑定分别用 PyO3、napi-rs 和统一的 C ABI 加 JSON 桥接。verify 除了回放最多 500 条真实调用，还会派生 NaN、负零、非 ASCII 文本等边界用例，并让原实现回答收缩输入，一致率不到 100% 一律不许上线。
